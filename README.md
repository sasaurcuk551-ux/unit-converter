# Конвертер величин

Консольна програма на Python для конвертації одиниць.

## Можливості

- Довжина: мм, см, м, км, дюйм, фут, миля
- Вага: г, кг, т, унція, фунт
- Температура: Цельсій, Фаренгейт, Кельвін
- Валюта: за курсом, який вводить користувач

## Запуск

Потрібен Python 3.8 або новіший.

```bash
python converter.py
```

## Приклад

```
=== Конвертер величин ===
Меню:
1. Довжина
...

З (C, F, K): C
У (C, F, K): F
100.0 °C = 212.00 °F
```
